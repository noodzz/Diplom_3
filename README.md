# Diplom_3
## Stellar Burgers – Автотесты для UI
Автотесты для UI сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/)
## Технологии

|    Технология    |  Версия  |
|:----------------:|:--------:|
|       Java       |    11    |
|      JUnit       |  4.13.2  |
|   REST Assured   |  5.5.6   |
|      Allure      |  2.15.0  |
|     Selenium     | 3.141.59 |
|      Maven       |  4.0.0   |
| WebDriverManager |  6.1.0   |

## Что тестируется
* **Регистрация пользователя** – успешная, с некорректным паролем
* **Логин пользователя** – по кнопке «Войти в аккаунт» на главной, через кнопку «Личный кабинет», через кнопку в форме регистрации, через кнопку в форме восстановления пароля 
* **Конструктор бургера** – переходы к разделам «Булки», «Соусы», «Начинки»

## Запуск тестов в Chrome
```bash
mvn clean test -Dbrowser=chrome
```
## Запуск тестов в Яндекс.Браузере
```bash
mvn clean test -Dbrowser=yandex
```
## Генерация отчета Allure
```bash
mvn allure:serve
```
